# 500 предложений API для VoidGram iOS

Это исходный список rndm (версия 1.0, 02.11.2026). Он остаётся **предложением**, а не обещанием:
какие методы уже отвечают в этой сборке, возвращает `voidgram.sdk.capabilities()` (в Python и Lua —
`void.sdk.capabilities()`). Реализованные в этой ветке методы отмечены в `sdk/API.md`.

Новые имена — `void.*`; в JavaScript из-за зарезервированного слова используется `voidgram.*`.
Старые `ayu.*` работают как тот же объект. Ниже исходный текст без изменений.

---

AYUGRAM iOS — 500 ПРЕДЛОЖЕНИЙ ДЛЯ PLUGIN API
Версия документа: 1.0 | Дата: 02.11.2026
Авторская подборка для разработчиков AyuGram iOS / rndm
Источник для сопоставления: https://github.com/dsn2fvhmn4-lgtm/AyuGramm-IOS/blob/main/docs/CODE_PLUGINS.md

ВАЖНО: Это перечень ПРЕДЛАГАЕМЫХ API, а не уже реализованные методы и не готовый программный модуль.
Некоторые близкие возможности уже могут быть встроены в текущую версию AyuGram; перед реализацией
следует сверить интерфейсы с исходниками, унифицировать названия и убрать дублирующее поведение.
Методы ниже — проектные имена и короткие функциональные требования, не обещание совместимости.

ПРИНЦИПЫ РЕАЛИЗАЦИИ
• Единый контракт для JavaScript, Python и Rust/WASM по мере технической возможности.
• Декларативный UI: приложение рисует и управляет событиями, плагин описывает компоненты.
• Персональные данные доступны только по выбранному пользователем действию и разрешению.
• Никаких скрытых отправок сообщений, обхода ограничений Telegram и поддельной верификации.
• Отзыв разрешений, очистка хуков и UI после отключения, лимиты по памяти/CPU/FPS.
• Версионирование, доступность для VoiceOver, Reduce Motion, энергосбережение, диагностика.
